## 🎯 **RESUMEN EJECUTIVO** *(Elevator Pitch)*

**ReporteSeguro** es la **plataforma SaaS líder en gestión de seguridad industrial** que transforma empresas mineras, petroleras y de construcción en organizaciones **Zero Accidentes**.

### **¿Qué Hace?**
Sistema integral que digitaliza, automatiza y optimiza **todos los procesos de seguridad industrial** desde reportes hasta inventarios EPP.

### **¿Para Quién?**
Empresas de **industrias de alto riesgo** (minería, petróleo, construcción, energía) con 50+ empleados que buscan:
- ✅ Reducir accidentes laborales 60%+
- ✅ Cumplir normativas ISO 45001/OSHA 
- ✅ Ahorrar $200K+ anuales en costos operativos
- ✅ Obtener certificaciones internacionales

### **¿Qué Problema Resuelve?**
- 📋 **Reportes manuales** → **Reportes digitales en 90 segundos**

## 🛠️ **INSTALACIÓN Y SETUP EMPRESARIAL**

### ⚡ **Quick Start (5 minutos)**

```bash
# 1. Clone del repositorio
git clone https://github.com/AndresBenit/reporteseguro-app.git
cd reporteseguro-app

# 2. Instalación dependencias
npm install

# 3. Configuración environment
cp .env.example .env.local
# Editar .env.local con credenciales Supabase

# 4. Desarrollo local
npm run dev
```

### 🏢 **Setup Enterprise**

#### **🔥 Supabase Configuration**
1. **Proyecto Supabase**: [console.supabase.com](https://console.supabase.com)
2. **Database Schema**: Ejecutar scripts en `/database/schema.sql`
3. **Row Level Security**: Aplicar políticas de `/database/security.sql`
4. **Storage Policies**: Configurar buckets para archivos
5. **Edge Functions**: Deploy funciones serverless

#### **🌐 Production Deployment**
```bash
# Vercel (Recomendado)
vercel --prod

# Docker Enterprise
docker build -t reporteseguro:latest .
docker run -d -p 80:80 reporteseguro:latest

# AWS/Azure/GCP
# Documentación completa en /docs/deployment/
```
