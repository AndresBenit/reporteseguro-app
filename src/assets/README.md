# 📁 Assets ReporteSeguro

## 📂 Estructura de Carpetas

### 🎨 `/logos/`
Coloca aquí los logos de la empresa:
- `logo-main.png` - Logo principal (fondo blanco)
- `logo-white.png` - Logo blanco (para fondos oscuros)
- `logo-icon.png` - Icono/isotipo solo
- `logo-horizontal.png` - Logo horizontal
- `logo-vertical.png` - Logo vertical

### 🖼️ `/images/`
Imágenes generales:
- `hero-bg.jpg` - Imagen de fondo principal
- `dashboard-preview.png` - Preview del dashboard
- `empresa-foto.jpg` - Foto de la empresa/instalaciones

### 🔍 `/icons/`
Iconos adicionales:
- `favicon.ico` - Favicon del sitio
- `apple-touch-icon.png` - Icono para iOS
- `android-chrome-192x192.png` - Icono para Android

## 📝 Formatos Recomendados
- **Logos**: PNG con transparencia, SVG preferible
- **Imágenes**: JPG para fotos, PNG para gráficos
- **Tamaños**: Logo principal máximo 500px de ancho
- **Resolución**: 2x para pantallas retina

## 🚀 Uso en Código
```jsx
import logoMain from '../assets/logos/logo-main.png';
import heroImage from '../assets/images/hero-bg.jpg';
```
